# datastar.nvim

Datastar language support for Neovim.

> [!NOTE]
> This project is being initialized. Syntax highlighting and language-server support are not implemented yet.

## Goals

- Highlight Datastar attributes and expressions in HTML and template files.
- Support Django templates (`htmldjango`) as a first-class filetype.
- Integrate Datastar completion, diagnostics, hover information, navigation, rename, and signature help through Neovim's built-in LSP client.
- Keep Datastar language data synchronized with the official editor extension.
