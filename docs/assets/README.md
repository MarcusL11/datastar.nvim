# datastar.nvim artwork

This directory contains the visual identity for `datastar.nvim`.

- `datastar-nvim-logo.svg`: wordmark for light backgrounds.
- `datastar-nvim-logo-dark.svg`: wordmark for dark backgrounds.
- `datastar-nvim-social.svg`: editable source for the GitHub social preview.
- `datastar-nvim-social.png`: 1280×640 rendered social preview.

The assets use an original, typography-led treatment focused on Datastar syntax
highlighting in Neovim. No third-party logo artwork is included.
